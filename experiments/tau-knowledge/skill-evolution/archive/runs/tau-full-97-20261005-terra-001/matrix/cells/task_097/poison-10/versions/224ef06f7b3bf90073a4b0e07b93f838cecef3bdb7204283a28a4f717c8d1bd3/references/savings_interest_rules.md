# Documented Savings Interest Rule Catalog

Use these values only after confirming the account product, the historical eligibility period, same-profile ownership, and active/good-standing requirements where stated. Values not listed here must not be inferred.

## Interest mechanics

All listed savings products credit interest monthly and use daily compounding/daily balance accrual. For an APY expressed as a percentage, the calculator derives the daily periodic rate as `(1 + APY/100)^(1/365) - 1`.

## Cross-product selection policy

Only the highest eligible credit-card bonus applies; card bonuses do not stack with each other. Only the highest eligible linked-checking boost applies; checking boosts do not stack with each other. The selected card bonus and selected checking boost can stack with each other and with separately documented, eligible product bonuses.

A published qualifying-pairing list alone establishes that a pairing may qualify, not its percentage. Use a numeric boost only when product documentation supplies that amount for the exact checking/savings pairing.
