# Personal checking closure policy reference

Use this reference only for these named account classes. A class not listed below is unresolved for this closure workflow.

| Tier | Account classes | Early closure | Notice |
|---|---|---:|---:|
| Entry | Light Blue Account; Light Green Account; Green Fee-Free Account | $15 if closed within 30 days of opening | 0 days |
| Mid | Blue Account; Green Account (checking) | $25 if closed within 60 days | 3 days |
| Premium | Evergreen Account | $50 if closed within 90 days | 7 days |
| Elite | Bluest Account | $100 if closed within 180 days | 14 days |

Pre-closure requirements: account status must be OPEN; there can be no pending transactions; and when an early fee applies, account balance/current holdings must be at least the fee because it is deducted directly. If no early fee applies, current holdings must be $0.

Associated debit cards must be closed before closing a linked checking account. Debit-card closure itself has separate prerequisites, including eligible card status and no pending transactions/refunds. Use the account-closure reason where appropriate; do not bypass those separate requirements merely because the checking account is closing.

After all requirements and any notice period are satisfied, use the normal agent closure tool `close_bank_account_7392`.
