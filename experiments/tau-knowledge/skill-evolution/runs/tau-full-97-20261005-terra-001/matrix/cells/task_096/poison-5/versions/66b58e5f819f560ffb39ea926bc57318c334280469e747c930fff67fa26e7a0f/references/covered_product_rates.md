# Covered product rates and eligibility evidence

Use these rates only after confirming active products under the same customer profile. Values are APY percentage-point additions.

## Bronze Savings

- Base APY: 2.0%.
- Qualifying checking boosts relevant to the documented pairings:
  - Bluest Account: +0.7% for Bronze Savings.
  - Green Fee-Free Account: +0.4% for Bronze Savings.
- Credit-card bonuses:
  - Bronze Rewards Card: +0.1%
  - Silver Rewards Card: +0%
  - Gold Rewards Card: +0.25%
  - Platinum Rewards Card: +0.55%
  - Diamond Elite Card: +0.15%
  - EcoCard: +0%
  - Green Rewards Card: +0.2%
  - Crypto-Cash Back Card: +0.3%

Bronze interest compounds daily and is credited monthly. Balance fluctuations affect the credited amount.

## Combination rules

- Select only the highest applicable active credit-card bonus; do not sum card bonuses.
- Select only the highest applicable active checking boost; do not sum checking boosts.
- The selected checking boost and selected card bonus are additive to the savings base APY.
- Only specifically documented checking–savings pairings qualify. No boost should be inferred from a similarly named or otherwise unlisted pairing.
