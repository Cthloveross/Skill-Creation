# Checking early-direct-deposit lookup reference

Use this reference only for the supplied Rho-Bank checking terms. Check current terms again if a later source changes them.

## Exact-class results

- **Blue Account** — Early direct deposit: 1 day before payday.
- **Green Account (checking)** — Eligible direct deposits up to 1 day early. Availability depends on when the payer submits the deposit; funds can post up to 1 day early.
- **Evergreen Account** — Eligible paycheck up to 2 days early.
- **Bluest Account** — Early direct deposit: 2 days before payday.
- **Purple Account** — Early direct deposit: 2 days early.
- **Light Blue Account** — Early direct deposit: 0 days before payday.

## Response rules

1. Name the exact checking class, especially where an account name also exists as a savings product.
2. Retain qualifiers: say “eligible” and “up to” where the terms do so.
3. Never turn an “up to 1 day” or “up to 2 days” statement into a guarantee.
4. When asked about Green Account (checking), answer yes, identify early direct deposit, and say “up to 1 day early.” Mention the payer-submission dependency.
5. When comparing alternatives, distinguish one-day choices (Blue, Green) from documented two-day choices (Evergreen, Bluest, Purple).
6. Product information alone does not select or authorize account opening. Ask for the customer's exact official selected class and separate explicit opening authorization afterward.
