## 必须一起读的限制

1. `rollout_result_unknown` / `verifier_initialization_result_unknown` 共 10 条，几乎全是 **执行器或 Verifier 输入超过 114688 token 上限**（长环境、长公开轨迹），是协议上限，不是基础设施故障；补跑中仍然出现。
2. 三道 Java 题（`flink-query`、`spring-boot-jakarta-migration`、`fix-build-google-auto`）的官方 grader 以 uid 10001 运行时 JVM 无 home 目录，Maven 用不了预热缓存；代理检查认为即使解法正确也可能被打 0。相关分数需要人工复核。
3. 9 道题的运行时镜像 python3 不是 3.11 或没有 pip，Verifier 依赖改用 uv 安装的独立 CPython 3.11（锁文件 `verifier_python_mode: standalone`），其官方 test.sh 仍在原环境运行。
4. 其余限制（Verifier 升级违规、测试程序错误、超时重发为协议偏离、单次采样、费用未测）与 τ 结果说明相同。provider usage 合计：请求 10,925 次，输入 2.01 亿 token（缓存 0.99 亿），输出 857 万 token。
