# Supported Platinum Rewards Card travel-related facts

Use these facts only for the Platinum Rewards Card described in the available documentation.

- Enhanced fraud protection and real-time monitoring are provided. A transaction that appears risky may trigger an alert asking the cardholder to confirm or deny the charge.
- If the cardholder denies a transaction, it is declined and the card can be immediately secured while an investigation occurs.
- The documentation recommends enabling transaction alerts and international-use alerts and keeping contact details current so time-sensitive prompts can be received. Fraud-alert handling has a target response within 17 minutes.
- The card has a 0% foreign transaction fee on international purchases.
- The card can be temporarily locked if misplaced and unlocked when found. A card number can be replaced quickly if compromise is suspected.
- The documentation does not establish a travel-notification feature or procedure. It does not document an app route, online-banking route, phone channel, form, required dates, how far in advance to notify, or whether a notice is required for foreign use.

Boundary: international-use alerts and a travel notification are separate concepts. Do not represent an alert setting as a completed travel notice.
