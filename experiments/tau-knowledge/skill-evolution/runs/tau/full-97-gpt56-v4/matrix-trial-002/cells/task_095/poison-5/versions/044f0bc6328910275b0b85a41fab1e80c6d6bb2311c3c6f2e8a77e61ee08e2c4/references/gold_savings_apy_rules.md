# Gold Savings APY policy reference

## Base and accrual

- Gold Savings base APY: 5.5%.
- Documented minimum-balance condition: $10,000.
- Interest compounds daily and is credited monthly.

## Gold Savings credit-card bonuses

Eligible same-profile cards provide the following Gold Savings APY bonuses. When more than one eligible active card is held, use only the highest bonus.

| Card type | Bonus APY percentage points |
|---|---:|
| Bronze Rewards Card | 0.15 |
| Silver Rewards Card | 0.20 |
| Gold Rewards Card | 0.025 |
| Platinum Rewards Card | 0.15 |
| Diamond Elite Card | 0.30 |
| EcoCard | 0.60 |
| Green Rewards Card | 0.35 |
| Crypto-Cash Back Card | 0.00 |

## Gold Savings checking boosts

Only documented checking–savings pairings are eligible. For a Gold Savings account, the supplied product documents identify these pairings and boosts:

| Checking type | Gold Savings boost, percentage points |
|---|---:|
| Green Account | 0.75 |
| Purple Account | 0.10 |

When more than one qualifying active checking account is held, use only the highest checking boost. A selected checking boost is additive to the base APY and selected credit-card bonus. Other listed checking/savings pairings do not establish eligibility for Gold Savings unless their own product documentation explicitly does so.

## Incident procedure

A missing qualifying boost or other incorrect savings interest calculation can require an internal discrepancy report. For an established underpayment, apply the savings credit before submitting that report. Exact statement period, actual APY, and balance basis are required to establish a dollar correction.
