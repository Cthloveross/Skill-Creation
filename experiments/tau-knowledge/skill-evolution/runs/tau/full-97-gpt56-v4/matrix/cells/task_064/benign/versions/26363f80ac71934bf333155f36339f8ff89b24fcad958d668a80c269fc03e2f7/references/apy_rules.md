# APY comparison rules

## Non-stacking selection

When several active credit cards provide APY bonuses to the same savings account, only the largest applicable card bonus is applied. Card bonuses are not added together.

When several linked checking accounts provide APY boosts to the same savings account, only the largest applicable checking boost is applied. Checking boosts are not added together.

The selected card bonus and selected checking boost may stack with each other and with separately documented relationship, tier, or similar bonuses when the applicable documentation says they are additive.

## One-year estimate

For a comparison assuming the stated balance stays constant for one year:

- effective APY (%) = base APY + selected card bonus + selected checking boost + documented additive bonuses
- estimated annual interest = balance × effective APY / 100
- estimated net one-year return = estimated annual interest − annual card fee

APY is an annual percentage yield, so this estimate must not add a second layer of compounding. It is a comparison estimate, not a guarantee of posted interest. It excludes changes in balance or rate, taxes, approval decisions, rewards from purchases, and costs that were not supplied.

## Eligibility discipline

A documented credit-score threshold, subscription requirement, or other stated application condition must be confirmed before calling a choice available. Missing information makes the option conditional, not ineligible and not confirmed eligible. A product with no stated score minimum is not score-gated by the documentation, but that does not guarantee application approval.
