Dedicated senior support can help with profile updates, including mailing address, phone, and email. Customers can call the dedicated senior support number shown in account materials, on the back of the debit card, or in online/mobile banking; send a secure message in digital banking using the Senior Support topic; or request a call-back using digital-banking contact options. Standard identity authentication occurs before account details are discussed. Customers should have their name, account number if available, and government ID nearby if requested. Never request online/mobile banking passwords, and use secure messaging rather than regular email for sensitive information.
