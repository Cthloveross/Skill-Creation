# Linked checking/savings APY pairing reference

Use this reference only after confirming both accounts are under the same customer profile and active or otherwise eligible under the applicable product terms. A customer may have several qualifying checking accounts, but only the highest applicable checking boost may be used for one savings account. The exact boost percentage must be obtained from the relevant checking product documentation.

Qualifying account-class pairs:

| Checking account class | Savings account class |
|---|---|
| Green Account (checking) | Gold Account |
| Green Fee-Free Account | Bronze Account |
| Evergreen Account | Green Account |
| Blue Account | Silver Plus Account |
| Light Green Account | Diamond Elite Account |
| Dark Green Account | Bronze Account |
| Bluest Account | Silver Account |
| Purple Account | Platinum Plus Account |
| Gold Years Account | Gold Plus Account |
| Light Green Account | Platinum Account |
| Green Account (checking) | Silver Account |
| Evergreen Account | Diamond Elite Account |
| Bluest Account | Bronze Account |
| Purple Account | Gold Account |
| Gold Years Account | Silver Account |
| Blue Account | Platinum Account |
| Green Fee-Free Account | Gold Plus Account |
| Dark Green Account | Platinum Plus Account |

Card-linked bonuses likewise use only the highest applicable active-card bonus for the specific savings class; that one card bonus can be added to the selected checking boost when both apply. Do not use this pairing list to infer product eligibility, account status, the actual boost percentage, or a customer’s product choice.
