# LaTeX Display-Formula Extraction

## What this task requires

Given a PDF (the public input copies it to `/root/latex_paper.pdf`), produce
`/root/latex_formula_extraction.md` where:

1. **Only display-mode formulas** are extracted. A display-mode formula occupies its
   own line, is visually separated from prose, and may carry an equation number in
   the right margin. Inline math (`$...$` / `\(...\)` embedded in a sentence) is
   **excluded**. Not every page has display formulas.
2. Each formula is wrapped in `$$...$$` on **its own line**, must render identically
   to the PDF (rendering equivalence, not string equality, is the ground truth).
3. Equation-numbering artifacts (`\tag{...}`, trailing `\quad (3)` / `\qquad(1)`,
   bare trailing `(1)`) and trailing sentence punctuation (comma/period) are stripped.
   Internal whitespace is normalized to single spaces. Mathematical content is never
   altered (no renaming, reordering, simplifying, or style changes).
4. The file has **no duplicate lines** (dedup on content between the `$$`).
5. **Correctable errors** are detected and a fixed version is **appended after all
   originals** (originals are kept; corrections are additional lines, never
   replacements). Only fix syntax/typographical problems:
   - mismatched `\left`/`\right` delimiters,
   - misspelled LaTeX commands (e.g. `\alhpa`→`\alpha`, `\sinn`→`\sin`) when the
     rendered glyph clearly supports the fix,
   - missing grouping braces (e.g. `x_ij`→`x_{ij}`).
   Do **not** change physics/math meaning (sign errors, variable choices) or make
   stylistic/display changes (`\frac`↔`\dfrac`, `\cdot`↔`\times`, delimiter sizing).

See `references/method.md` for the full guidelines distilled from the background.

## Workflow for the executor

The mechanical parts (cleaning, dedup, bracket validation/auto-fix, file assembly)
are automated by `scripts/process.py`. The **visual extraction itself is yours** —
you read the PDF and transcribe each display formula to LaTeX, verifying it renders
like the page. Steps:

1. **Inspect the PDF.** Read text and layout. Useful commands if the tools exist:
   - `pdftotext -layout /root/latex_paper.pdf - | less` (text + rough layout),
   - `pdfinfo /root/latex_paper.pdf` (page count),
   - `pdftoppm -png -r 150 /root/latex_paper.pdf /tmp/pg` then view the PNGs to
     confirm which lines are display-mode and to read symbols precisely.
   Watch for **two-column layouts**: process each column independently; a display
   formula in column 2 may be centered relative to that column, not the page.
2. **Collect display formulas page by page.** For every page, list only own-line
   formulas. Transcribe each to LaTeX that renders the same (any equivalent source
   is fine — e.g. `\frac` vs `\dfrac`, optional braces around single tokens). Record
   them in the order they appear; keep repeats for now (dedup is automatic).
3. **Decide corrections.** For each formula check for the three correctable error
   classes above, confirming against the rendered page. Supply explicit fixes via
   `manual_corrections`. Leaving `auto_fix_brackets` on also auto-generates a
   candidate fix for any `\left`/`\right` mismatch; review it against the PDF and
   override with a `manual_corrections` entry if the context implies the other
   delimiter.
4. **Run the entrypoint** to clean, dedup, validate, append fixes, and write the file.
5. **Verify** the written file: originals first (one `$$...$$` per line, no dups),
   a blank line, then the appended corrected lines. Re-run after any edit so the
   deliverable is regenerated by the script, not hand-patched.

## scripts/process.py

Reads one JSON object from **stdin**, writes the deliverable, prints a JSON report
to **stdout**.

Input schema:
```json
{
  "output_path": "/root/latex_formula_extraction.md",
  "formulas": ["<raw latex of each display formula, with or without $$>", "..."],
  "manual_corrections": [{"original": "<formula as it appears>", "fixed": "<corrected>"}],
  "auto_fix_brackets": true
}
```
- `formulas` (required): raw transcriptions in page order; `$$` wrappers optional.
- `manual_corrections` (optional): explicit fixes; `original` is matched after the
  same cleaning that is applied to `formulas`.
- `auto_fix_brackets` (optional, default `true`): if a formula has a `\left`/`\right`
  mismatch and no manual correction, append a candidate fix (closing delimiter made
  to match its opener). `output_path` defaults to `/root/latex_formula_extraction.md`.

Output report fields: `output_path`, `cleaned` (deduped originals written),
`corrected` (appended lines), `bracket_issues` (per-formula validation findings,
including `unmatched` and `mismatches`), and `written` (byte count).

File layout produced:
```
$$original_1$$
$$original_2$$
...

$$fixed_1$$
$$fixed_2$$
```
(The blank line and second section appear only when there are corrections.)

### Runnable example
```bash
echo '{"formulas":["$$E = mc^2$$","$$ a + b , $$","$$E = mc^2$$","$$\\left\\{ u>0 \\right]$$"],"manual_corrections":[]}' \
  | python3 /app/environment/skills/current/scripts/process.py
cat /root/latex_formula_extraction.md
```
Here `$$E=mc^2$$` is deduped, the trailing comma and extra spaces are cleaned, and
the mismatched `\left\{ ... \right]` yields an appended `\left\{ u>0 \right\}`.

## Validating the bracket logic standalone
```bash
echo '{"formula":"\\left\\langle x \\right|"}' \
  | python3 /app/environment/skills/current/scripts/validate_brackets.py
```
Returns the detected `\left`/`\right` tokens, any `mismatches`/`unmatched`, and an
`auto_fix` suggestion. Delimiter coverage includes `()`, `[]`, `\{\}`,
`\langle\rangle`, `|`, `\|`, `\lvert\rvert`, `\lVert\rVert`, `<>`, and the invisible
`.` — angle brackets are explicitly handled.

## Handling missing data / unsupported cases
- If no display formulas exist on any page, write an empty (or whitespace-only) file
  by passing `"formulas": []`; do not invent formulas.
- If a mismatch's intended delimiter is ambiguous, pick the one supported by repeated
  notation elsewhere in the paper and pass it via `manual_corrections`; the auto-fix
  is only a default.
- Never silently replace an erroneous formula with its fix — both must appear.
- If PDF-rendering/OCR tools are unavailable, fall back to `pdftotext -layout` plus
  careful reading; still confirm each formula is display-mode and renders correctly.
